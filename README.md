# GULCE Admin Power
Minecraft Java Edition 1.21.11 admin datapack — plugin gibi çalışır.

## Özellikler
- İzin yönetimi
- 18+ eylem tipi
- Zamanlayıcı motoru
- Kit sistemi
- Log geçmişi
- Dialog arayüzü

## Kurulum
ZIP'i `saves/<dünya>/datapacks/` klasörüne at, `/reload` yap.

## Kullanım
/trigger gulce_menu set 1
